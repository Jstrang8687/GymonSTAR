# GymonSTAR monster art — Rare (tier 2) evolutions

These are evolutions of the tier-1 art in `monster-art-prompts.md`, not new
creatures: each one keeps the same species, exercise pose, and habitat as its
tier-1 form, and only adds what a real evolution would — larger and more
battle-hardened, a battle-worn armor/marking detail, and a faint aura in its
color. If tier 1 is Deltoid the rock wyrm lifting dumbbells on a mountain
peak, tier 2 is a bigger Deltoid with bone spikes and a storm rolling in —
recognizably the same monster, further along.

Same batch-paste approach as tier 1: paste one block, and if the tool returns
several distinct images in one response, move to the next block. If it only
gives you one image per message, paste the numbered creatures inside that
block individually instead.

## Filenames

`<key>_2.png` into `public/monstars/`. Lats uses the `back` basename:
`back_2.png`.

## Chest & Lats tip

Both already have real tier-1 art. If your tool supports image-attach, upload
`chest.png` / `back.png` alongside the prompt and ask it to evolve that exact
character — much closer match than text alone.
