# GymonSTAR monster art — Rare (tier 2) & Legendary (tier 3) evolutions

Updated to match the redesigned tier-1 species in `monster-art-prompts.md`
(each monster is now its own distinct creature, not a reptile-bodybuilder
reskin). Same batch-paste approach: each block below asks for several
distinct standalone images in one response. If a batch only returns one
image, paste the creatures inside it one at a time instead — same text,
just split by the numbered lines.

Every evolution keeps its tier-1 pose and habitat for continuity, but scales
up: **Rare** adds a battle-worn armor/marking detail and a faint aura;
**Legendary** is a towering mythic form with a full energy aura and a
storm-charged version of the same habitat.

## Filenames

Tier 2 → `<key>_2.png`, tier 3 → `<key>_3.png`, into `public/monstars/`.
Lats uses the `back` basename: `back_2.png` / `back_3.png`.

## Chest & Lats tip

Both already have real tier-1 art. If your tool supports image-attach, upload
`chest.png` / `back.png` alongside the prompt and ask it to evolve that exact
character — much closer match than text alone.
