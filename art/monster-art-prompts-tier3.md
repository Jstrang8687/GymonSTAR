# GymonSTAR monster art — Legendary (tier 3) evolutions

Final evolutions of the tier-1/tier-2 art. Same species, same exercise pose,
same habitat as before — these just go all the way: massive and mythic,
towering over the scene, fully armored/adorned, eyes glowing with power,
radiating intense energy in the monster's color, in a storm-charged or
epic version of the same setting. If tier 2 is a bigger Deltoid with bone
spikes on a stormy peak, tier 3 is a colossal Deltoid Colossus fully
plated in glowing stone armor with lightning striking the summit — same
monster, final form.

Same batch-paste approach: paste one block, and if the tool returns several
distinct images in one response, move to the next block. If it only gives
you one image per message, paste the numbered creatures inside that block
individually instead.

## Filenames

`<key>_3.png` into `public/monstars/`. Lats uses the `back` basename:
`back_3.png`.

## Chest & Lats tip

Both already have real tier-1 (and now tier-2) art. If your tool supports
image-attach, upload the existing art alongside the prompt and ask it to
evolve that exact character to its final form — closer match than text alone.
